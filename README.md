# Mone Brigaderia: app vitrine

App vitrine da Mone Brigaderia. A cliente vê os doces do dia, abre a ficha de cada um (descrição, glúten, lactose, composição) e faz a encomenda pelo WhatsApp. A dona controla tudo num painel: o que tem hoje e em que quantidade, doces sob encomenda e campanhas como Natal e Páscoa.

## Onde estamos

O projeto está na fase de **protótipo navegável**. Ainda não existe app rodando, banco de dados, servidor nem domínio.

## Como trabalhar juntos

1. Crie um branch por tarefa a partir do `main` (exemplo: `feature/ficha-do-doce`).
2. Abra um pull request para o `main` e peça revisão de outra pessoa do time.
3. Decisões que mudam o escopo entram em `docs/funcionalidades.md` no mesmo pull request.
